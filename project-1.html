This is a volumetric renderer being developed with UIUC Siggraph. So far we have set up an OpenGL window and a fragment shader that raymarches basic clouds. We have built physically accurate skies so far as well as clouds that correctly get colored from the atmosphere. We are ultimately trying to render realistic and physically accurate clouds.

I am building it by following the camera chapter of Physically Based Rendering (pbrt), which is written for a CPU ray tracer, and adapting it to a fragment shader.

I am currently building the pinhole camera. Next is orbit or fly controls that update the camera-to-world matrix each frame and send it to the shader as a uniform, then depth of field.
